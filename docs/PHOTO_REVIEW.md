## 6. Asset processing requirements

Before Stage 1:

- Confirm the selected hero and Soul source images with Shiv.
- Use originals as the source of truth; generated mockups are not source photographs.
- Export responsive WebP/AVIF variants and keep source originals outside the public bundle where appropriate.
- Use descriptive, stable filenames (for example, `shiv-hero-portrait.webp`, `shiv-soul-outdoor.webp`, `shiv-graduation.webp`).
- Preserve EXIF privacy; strip unnecessary location/device metadata from public derivatives.
- Do not upscale or retouch facial features in a way that changes identity.
- Keep images optimised and lazy-load below-the-fold assets.
- Do not publish third-party faces without appropriate permission.
